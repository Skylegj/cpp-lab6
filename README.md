## Задание

Дан интервал (c, d) и два произвольных массива Q, W размера n, k соответственно.

Найти сумму отрицательных элементов массива Q, не попадающих в интервал (c, d), и сумму отрицательных элементов массива W, не попадающих в интервал (c, d).

Исходные данные взять самостоятельно.

## Описание программы

Программа считывает границы интервала и элементы двух массивов.

Для вычисления суммы используется одна функция `calculateSum()`, которая принимает массив, его размер и границы интервала.

Элемент включается в сумму, если он отрицательный и находится вне открытого интервала (c, d). Границы интервала включаются в расчёт.

Функция вызывается отдельно для массивов Q и W.

## Входные данные

1. Границы интервала `c` и `d`.
    
2. Размер массива Q — `n`.
    
3. Элементы массива Q.
    
4. Размер массива W — `k`.
    
5. Элементы массива W.
    

Ограничения:

- Размер каждого массива — от 1 до 100.
    
- Модуль каждого элемента не превышает 1000.
    
- Левая граница интервала меньше правой.
    

## Выходные данные

Программа выводит суммы подходящих элементов массивов Q и W.

При некорректных входных данных выводится `INVALID`.

## Пример работы

**Ввод:**

```
-5 2
4
-8 -4 -2 3
4
-10 -5 -1 7
```

**Вывод:**

```
Q: -8
W: -15
```
